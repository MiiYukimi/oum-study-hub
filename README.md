# OUM Study Hub

Personal OUM MCQ exam revision site for two subjects.

## Site

Once GitHub Pages is enabled (Settings → Pages → Deploy from a branch → main / (root)):

- Study Hub: https://miiyukimi.github.io/oum-study-hub/
- MPU3223_V2 Entrepreneurship 2: https://miiyukimi.github.io/oum-study-hub/entrepreneurship/
- ABCM2103 Information Technology, Media and Society: https://miiyukimi.github.io/oum-study-hub/media-society/

## Practice structure

- MPU3223_V2: 10 Topics × 30 MCQ = 300 questions
- ABCM2103: 9 Topics × 30 MCQ = 270 questions
- Total: 570 original practice MCQs. They are **not official OUM past examination questions**.

Both subjects have immediate-feedback practice, 30-question mock tests, Chinese explanations, wrong-answer review, bookmarks, search, light/dark mode, and mobile-responsive layouts.


## Progress backup / 手動跨裝置同步

Open [the Study Hub homepage](https://miiyukimi.github.io/oum-study-hub/#backup) or use **進度備份／匯入** in either subject's toolbar.

1. On the device that has your latest progress, click **匯出兩科進度（JSON）**. Save the downloaded `OUM_Study_Hub_Backup_YYYY-MM-DD.json` file.
2. Transfer that JSON file to the other device (e.g. personal cloud drive, private message, or AirDrop).
3. On the second device, click **匯入進度（JSON）**, choose the file, and confirm.
4. Open the subject site to read your restored answers, wrong questions, bookmarks and mock scores.

**Important:** Import **replaces** existing progress for subjects included in the backup. It does not merge two devices' separate progress, and it is not automatic cloud sync. Export a new backup before changing devices, and back up any records you want to keep before importing. Never publish your exported backup file to the public repository.

## Notes

- Browser data is saved to localStorage and **will not sync across devices**.
- GitHub Pages for this public repository is **publicly accessible**; noindex and robots.txt do not create private access.
- Course material contains historical information; laws, government bodies, institutional arrangements and statistics may be outdated. This site is for examination revision and does not reflect up-to-date legal or regulatory advice.
- The original OUM PDF modules are not included in this repository.
